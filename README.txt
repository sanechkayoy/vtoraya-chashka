ВТОРАЯ ЧАШКА — сайт + админка (локальная демо-версия)

Что есть:
- сайт посетителя: http://localhost:3000
- админка: http://localhost:3000/admin
- меню, цены, отзывы и контакты хранятся в data/db.json
- изменения из админки появляются на сайте после сохранения.

Запуск:
1. Установите Node.js LTS с https://nodejs.org/
2. Откройте PowerShell в этой папке.
3. Выполните: node server.js
4. Откройте браузер: http://localhost:3000
5. Админка: http://localhost:3000/admin
6. Демо-пароль: coffee2026

ВАЖНО:
Это учебная локальная версия. Для передачи реальному бизнесу нужно развернуть сервер, заменить демо-пароль на безопасную авторизацию, включить HTTPS и хранить данные/пароли безопасно.
